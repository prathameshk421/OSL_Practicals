KNOWN ISSUES SPOTTED, NOT FIXED
- prac.sh uses the invalid integer-test operator -gte in the grade function.
  bash -n does not catch this runtime expression error.
- proccess_sched.cpp Round Robin does not skip already completed processes.
  It can count a completed process again and stop before all work is finished.
- CPU scheduling code assumes all processes are available at time zero and
  uses non-preemptive SJF/Priority. It does not take arrival times.
- fac.c uses a signed format specifier for an unsigned long long result and
  does not check factorial overflow. parent.c reports success whenever the
  child exits normally, even if the exit code is nonzero.
- The disk paste's SSTF search uses a fixed initial distance of 9999 and can
  index -1 for sufficiently large distances. SCAN modifies the request vector
  before C-SCAN runs. Inputs are not validated. Review before relying on it.
- Concurrent/shared-memory examples have not been behavior-tested. Passing
  compiler syntax checks does not verify synchronization or race freedom.

BUILD / RUN BASICS (LINUX)
Use each folder independently. Do not build every variant into one program.
C example: gcc filename.c -o program -pthread
C++ example: g++ proccess_sched.cpp -o scheduler
Corrected A7: gcc -std=c11 page_replacement_input.c -o a7
Then run ./a7 and enter the count, sequence, and frame count when prompted.
Shell example: bash prac.sh
For exec-factorial, build fac.c as fac in the same directory as parent:
  gcc fac.c -o fac
  gcc parent.c -o parent
  ./parent 5
For the two-peer shared-memory example, build shm1.c and shm2.c separately
with shm_com.h alongside them, then run in two terminals.
