# OS Laboratory Practicals

Study collection organized by the official PICT OSL assignment index.

Download the [complete organized ZIP](3-OSL_Practicals_public_ready.zip) or browse the assignment folders below.

Read [START_HERE.txt](START_HERE.txt) for assignment coverage, build commands,
remaining gaps and known issues. The included PDF is the official assignment
index, not a full lab manual.

- `Today_Uploads` and `Today_Paste`: supplied source files.
- `Original_References` and `Additional_Originals`: recovered originals.
- `07_Page_Replacement/Corrected_A7`: input-based version with runtime tests.

All eight assignments have relevant material. This does not mean every
requirement is complete or every program is correct. A1's 20-command demo and
A6's explicit fixed-partition/non-contiguous allocation remain unlocated.

Original sources remain separate from the A7 correction. No other code fixes
were made. C++ is allowed. See the A7 test report.

## Source preservation

Original code is separate from the corrected A7 version. The browsable
`08_Disk_Scheduling/Today_Paste/disk_scheduling.cpp` has one final newline
added by GitHub's editor; its code is otherwise unchanged. The ZIP retains
the exact original bytes for every source. All other browsable source and
support files were checked against the organized ZIP.
